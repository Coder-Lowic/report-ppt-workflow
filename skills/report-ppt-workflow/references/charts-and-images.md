# 图表与配图规范(report-ppt-workflow)

台账数据 → PPT 页面元素的落地规范。三条铁律:**数据只从台账取、图表优先于文字、每张图注明口径**。

---

## 一、三大图表件型(覆盖汇报 90% 场景)

### ① 指标卡(总体情况页/成效首页)
- 用途:4–6 个核心数字一屏呈现;
- 结构:`大数字(同比箭头)` + `指标名` + `一句总结导语`;
- 数据来源:台账的合计行/最新期数值;同比 = (本期-基期)/基期,**必须注明基期**;
- 排版:等宽网格,数字字号 ≥ 页面最大字号(48pt+),箭头↑绿↓红按语义定(政务场景注意:增长不一定绿,视指标性质)。

### ② 趋势图(成效页/进度页)
- 用途:月度/季度序列数据(如网办率 75.53%→…→79.17%);
- 图型:折线(趋势)或柱状(对比);≤8 个数据点,多了就按季度聚合;
- 落地方式(按环境任选其一):① matplotlib 出 PNG 嵌入(通用;中文需 `plt.rcParams['font.sans-serif']=['Microsoft YaHei']`,Linux 用 Noto Sans CJK);② 环境有 pyecharts/ECharts 能力则渲染静态图嵌入;③ 简单趋势直接用兜底引擎的表格/指标卡呈现;
- 必带元素:基期起点标注、数据说明脚注(如"9月现场抽样均值,非全量统计")。

### ③ 进度一览表(年度要点对照页)
- 用途:对照年初计划逐条标注状态;
- 结构:事项 | 年度目标 | 当前进度 | 状态(✅已完成 / 🔄推进中 / ⚠️滞后);
- 状态用色从设计 Token 表取(完成=主色、滞后=强调色),不引入新色。

**图表自检**:每个数字能在台账里指出具体单元格;找不到 → 改用"【留白待核】"或删除该图。

---

## 二、配图策略

### 何时配图(优先级从高到低)
1. **工作照/活动照**(用户材料自带):最有说服力,优先用——排版见下方"照片墙";
2. **意象图**(搜索):封面/章节页的氛围图,可搜;
3. **数据可视化**(生成):永远优先于装饰性图片;
4. **AI 生图**:正式汇报场合**默认不用**(合规风险),用户明确要求除外。

### 搜图工具与规范
- 搜图是**可选增强**:环境有 image-search 插件(ZCode:`mcp__plugin_image-search_image_search__search_image`)或联网搜索能力时可用;没有则请用户提供或改纯排版,不阻塞流程;
- 政务/正式场合搜图红线:不出现明确Logo/水印/欧美商务图冒充本单位;人物图注意肖像权;优先无版权问题的图;
- 搜不到合适的 → 不配图,用纯色块+大标题,不要硬凑。

### 照片墙(一页多图,视频场景:"领导丢来一堆工作照")
- ≤9 张:3×3 等宽网格;>9 张:分组多次页,或"主图(2倍宽)+小图列"布局;
- 统一裁切比例(建议 4:3 或 1:1),统一轻微圆角/描边;
- 每组配一行小标题(如"窗口服务""上门帮办"),图片下方不写长说明;
- 工作照质量差(模糊/歪斜)时只选最好的 3–4 张,宁缺毋滥。
