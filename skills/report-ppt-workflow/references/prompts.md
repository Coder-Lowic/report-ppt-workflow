# 提示词模板(report-ppt-workflow)

三段模板来自视频 BV1kLWu64EN3 的画面原文,已整理为填空版。给用户输出时保留【】占位并说明替换方法。

---

## ① 主提示词:资料整理 + 大纲定制(一步到位)

> 适用:Step 1/Step 2。把【】替换为实际情况,材料粘贴或作为附件一起发送。

```
##【角色介绍】
我是【单位名称】的【职位】,负责【核心职责】,正在准备一份工作汇报PPT。

##【任务背景】
现需制作《【汇报主题,如:2026年前三季度××工作情况汇报】》PPT,
汇报对象是【区政府分管领导/部门负责人/内部同事/客户……】,
用于【专题推进会/年终总结/项目汇报……】场合,
汇报时长【10分钟】左右,PPT约【15】页。
汇报目的是【展示成效、说明问题、争取支持】。

##【细节约束】
1. 完整结构:包含封面页、目录页、主体章节和封底页;
2. 内容模块:按"总体情况—重点成效—存在问题—下一步安排"展开,逻辑清晰、层次分明;
3. 重点突出:聚焦【核心业务方向】等工作;
4. 资料结合:以下是我的原始材料【粘贴或上传材料】。全部数字必须取自材料,与总结口径
   一致;同比数据注明对比基期;未掌握的数据留白待核,切勿估算填充;
5. 呈现风格:符合【体制内正式汇报/商务汇报】要求,语言严谨精练,表述对齐
   【相关政策口径或上级要求】,突出工作成果、问题分析和整改方向。

##【输出格式】请依次输出三部分:
① 整体框架:将内容归纳为3—5个逻辑清晰的板块,按合适的汇报顺序排列,说明整体汇报
   逻辑,并给出每个板块的时长占比和页数配比;
② 资料清单:用表格列出"板块标题、主要内容(分条)、需要准备的资料";
③ 逐页大纲:一份【15】页左右的完整PPT大纲,每页只列"页码、页面标题、核心内容要点、
   建议展示形式(如:4—6个大数字指标卡+一句导语 / 进度一览表 / 趋势图 / 案例页)",
   不需要展开正文或撰写逐页讲稿。
```

收到结果后的自检口诀(也适用于检验自己产出):
- 配比:成效约55% / 问题约15% / 请求约25%;
- 咬合:每条问题都有一条对应举措或请求,无落空问题、无来由请求。

## ② 套话改写提示词(成果公式)

> 适用:Step 3 改写空泛表述。

```
请把下面这段工作总结套话,按照"成果 = 目标 + 动作 + 结果 + 价值"公式重写:
- 一句话概括(要解决什么问题);
- 目标:量化目标;
- 动作:具体采取了哪些措施;
- 结果:完成量、完成率、同比变化;
- 价值:对业务或管理意味着什么。
数据只能从原文提取,不得编造:

【粘贴套话原文】
```

改写效果示例:
- 改前:"本季度持续加强设备巡检管理,扎实推进隐患排查整治工作,不断完善工作机制,
  全面压实责任……取得良好成效……奠定了坚实基础。"
- 改后:"本季度持续加强设备巡检,扎实推进隐患整改,取得良好成效。**计划100台,完成
  90台;发现40项隐患,整改32项。**"
  - 目标:设备巡检100台
  - 动作:分区检查 / 台账跟踪 / 复核确认
  - 结果:完成90台(90%);发现40项隐患,整改32项(80%)
  - 价值:故障率明显下降,保障全年安全运行

## ③ 金句模仿提示词(笔杆子金句)

> 适用:Step 3 需要提纲挈领的金句时。参考文案优先用"领导夸过的/单位公认的好句子"。

```
我在【事业单位/公司】上班,正在准备一场PPT演讲,请帮我撰写演讲金句文案,
要求让听众产生共情,并传达正能量。请按以下步骤完成:
第一步:先询问我想要表达的核心内容;
第二步:分析以下参考文案的风格特征:
【粘贴3—5条参考金句,如:
  事业只有干出来的精彩,没有等出来的辉煌。
  敢啃"硬骨头",敢挑"硬担子",敢攻"硬任务"。】
第三步:模仿参考文案的语气,撰写3条金句文案,并说明写作思路。
要求:每条不超过30个字;务必基于我想表达的核心内容。
```
