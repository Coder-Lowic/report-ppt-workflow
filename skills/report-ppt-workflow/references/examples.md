# 正反示例(report-ppt-workflow)

判断大纲/文稿质量的标准:通稿特征 = 差;数据支撑 + 咬合 = 好。以下示例均来自视频 BV1kLWu64EN3 的对比演示。

---

## 一、大纲:优化前(差)vs 优化后(好)

### ❌ 优化前:AI直接生成的通稿大纲(典型病症)

| 页面 | 内容 | 病症 |
|---|---|---|
| 封面 | 只有汇报主题 | 看不出"讲什么、为什么讲" |
| 总体工作情况 | "在XX领导下,坚持XX导向,围绕XX目标,取得新进展新成效" | 一段定性描述,**无任何数字**,配"成果显著"四字标语 |
| 主要工作成绩 | "完成XX任务、推进XX工作、落实XX要求" | 无进度对比、无数据支撑 |
| 存在的不足 | "一是思想认识有待提高;二是工作力度有待加强;三是方式方法有待创新" | 三条"有待",无一对应具体事例和数据 |
| 问题原因分析 | "主观上……客观上……" | 各一句套话,不落部门、不落机制 |
| 下一步总体思路 | "以XX为统领,以XX为主线,以XX为抓手,工作再上新台阶" | "统领—主线—抓手"万能句式,配无内容的三角结构图 |
| 重点举措(两页) | "进一步加强/进一步深化/进一步优化";"持续推进/不断强化/努力实现" | "三个进一步"无时限、无责任、无量化目标,**两页可互换** |
| 保障措施 | "加强组织领导、强化督查考核、营造良好氛围" | 万能尾巴 |

### ✅ 优化后:按"角色+任务+细节+格式"提问的生成效果

| 页面 | 内容 | 好在哪 |
|---|---|---|
| 封面 | 标题《2026年前三季度政务服务提质增效工作情况汇报》+ 汇报单位、汇报场合、汇报时间;可加提纲挈领副标题,如"聚焦高效办成一件事,打造政务服务升级版";政务红/深蓝主色,主标题+副标题+单位落款 | 一眼看清谁汇报、在哪讲、讲什么 |
| 目录 | "目录/汇报提纲",三行文字目录,无图标、无导语 | 克制 |
| 总体工作情况 | **4–6个大数字指标卡(数字+同比箭头)+ 一句总结性导语**,避免整段文字。指标例:受理总量、日均办件量及同比、进驻部门数、可办事项数、12345工单量及办结率 | 结论前置、数据说话 |
| 年度重点工作推进一览 | 对照年初工作要点逐条标注进度:已完成/推进中,**状态标注一目了然** | 有对照、有进度 |
| 成效页(每页) | 一个成效主题 + 具体数据(如:平均办理时长、承诺时限压缩比例、减材料/减环节、"一件事"集成办落地数)+ 数据说明(抽样口径等) | 页页有硬货,且注明口径 |

## 二、文稿:数据纪律示范(公文生成的好例子)

AI 收到材料后生成内容时,开头先给使用规则,正文页页有真实数据+口径说明:

> 1. **数据纪律**:全部数字取自台账,与总结口径一致;同比数据注明对比基期;未掌握的数据留白待核,切勿估算填充。
> 2. **节奏**:六页成效页每页讲40–50秒;问题部分点到为止,重点放在"恳请支持事项"页。
> 3. **政策对齐**:表述对齐上级要求(如"高效办成一件事"常态化推进、"人工智能+政务服务"),避免"唯满意率"。
> 4. **版式**:政务红或深蓝主色;每页文字不超过80字;数据图表优先于文字段落。

正文示例(注意数据密度和"数据说明"的严谨性):

- **核心指标概览(2026年1–9月)**:受理总量 258,050 件;办结总量 257,460 件;综合网办率 77.41%(网上受理 199,769 件);按时办结率 99.46%;"好差评"好评率 99.69%(有效评价 58,816 条,好评 58,636 条)。
- **时限压减**:9月窗口现场抽样平均等候 12.8 分钟,较1月(21.6分钟)下降 8.8 分钟。*数据说明:等候时长为9月现场抽样均值,非全量统计。*
- **帮办代办**:累计 7,426 件次,其中老年人、行动不便群众 2,161 件次。*数据说明:帮办数据为"件次",含同一群众多次服务情况。*

## 三、排版:万能四步分层法完整案例(分组→提炼→突出→留白)

**原文(约300字,一页全是字、一个字不能删)**:

> 这一年来,我的工作主要围绕日常客户维护、新客开发,以及团队协作支持和新人培训三个方面展开。其中,日常客户维护占整体工作的50%,全年维护250多家存量客户,老客户销售额1.26亿元;每月定期拜访30家重点客户,全年累计拜访360次,客户复购率稳定在60%以上;协助解决85件产品使用问题,响应时间控制在24小时以内,客户满意度提升到86%。新客开发占30%,通过行业展会、线上推广和客户转介绍,全年跟进80多家潜在客户,线索转化率35%,最终签约50家,开发效率同比提升15%。团队协作支持和新人培训占20%,提出"大客户分级跟进"建议并被团队采纳,推动团队整体转化率提升8%。

**四步改造**:

1. **分组**(按主题):客户维护 / 新客开发 / 团队协作与培训;
2. **提炼**(小标题 + 占比):主要工作 50%·日常客户维护 | 次要工作 30%·新客开发 | 辅助工作 20%·团队协作及新人培训;
3. **突出**(放大关键数据):
   - 维护存量客户 **250+家** · 销售额 **1.26亿元** · 月均拜访 **30家**(全年360次)· 复购率 **60%+** · 解决问题 **85件** · 响应 **≤24小时** · 满意度 **86%**
   - 跟进潜客 **80+家** · 转化率 **35%** · 签约 **50家** · 效率 **+15%**
   - "大客户分级跟进"被采纳 · 团队转化率 **+8%**
4. **留白**:三栏拉开间距,每组内部"标签+大数字"上下分层,句式短、行间空。

**结果:文字一句没删,页面一目了然。**

## 四、配色:HSL 十字正交法操作演示

> 口诀:**纵向尝试更亮和更暗的颜色,形成深浅层次;横向尝试相邻色相,作为多组区分的候选颜色。**

1. 在取色器把颜色模式从 RGB 改为 **HSL**;
2. 选定主题色,例:#248CD2(H=145, S=180, L=123);
3. **向上找浅色**:调高 L → #73B8E7(L=173),用于背景/弱化元素;
4. **向下找深色**:调低 L → #1A6496(L=88),用于标题/强调;
5. **相邻色**:微调 H → #1A9690(H=125),仅在需要第二组区分色时少量使用;
6. 整页保持同一色系深浅变化,克制、不花哨——正式汇报场合优先此法。
