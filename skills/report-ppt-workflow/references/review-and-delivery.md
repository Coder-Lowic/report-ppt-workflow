# 审校与交付(report-ppt-workflow)

交付前的最后一道闸。审校清单不过,不出门。

---

## 一、交付前审校清单(10 项,逐项打勾)

### 数据类(最易翻车)
- [ ] **三处对账**:同一个数字在「大纲、文稿、图表」三处出现时完全一致(抽查全部关键指标);
- [ ] **同比基期**:所有"同比/环比/较X月"都注明了对比基期;
- [ ] **口径说明**:抽样数据、非全量统计、特殊口径都有脚注(如"件次,含同一群众多次服务");
- [ ] **留白项**:所有【留白待核】要么已补真实数据,要么明确标注"待核",没有一个是估算值;
- [ ] **加总校验**:表格/指标卡的合计 = 分项之和;百分比之和合理。

### 逻辑类
- [ ] **咬合检查**:每条问题在"举措/请求"部分有对应项;每个请求能追溯到具体问题;
- [ ] **结论前置**:每个板块第一页先给结论,不是先铺过程。

### 表述类
- [ ] **无通稿句**:全文搜"进一步加强、持续推进、取得良好成效、在XX领导下"——命中即按套话改写公式重写;
- [ ] **口径对齐**:政策提法与用户提供的上级口径逐字一致(如"高效办成一件事"不能写成"一件事高效办成",不能多字少字或擅加引号);
- [ ] **敏感红线**:无夸大表述("全国领先"→"处于前列")、无未授权数据披露。

## 二、逐页讲稿(Step 3.5 产出)

大纲阶段不写讲稿,但**交付前**为需要口头汇报的页面补讲稿并写入 pptx 演讲者备注:

### 计时公式(来自视频方法论)
- 总时长 = 汇报时长 × 0.9(留 10% 缓冲);
- 成效页:每页 40–60 秒;问题页:点到为止(每页 ≤30 秒);"请求事项"页:放慢,每页 60–90 秒;
- 封面/目录/结尾:合计 ≤ 总时长 10%。

### 讲稿模板(每页备注三行)
```
[本页用时] 45秒
[开口第一句] 先给结论:"今年以来,××工作总体呈现三个特点……"
[衔接下一页] "具体是怎么做到的?下一页看数据。"
```

### 写入 pptx 备注(自带脚本)
```bash
# notes.json: {"1": "讲稿…", "2": "…"}(页码从1起)
python scripts/write_notes.py deck.pptx notes.json
```
环境无 Python 时,告知用户逐页手贴备注(内容已按页给全)。

## 三、交付格式(按场合选择)

| 场景 | 格式 | 生成方式 |
|---|---|---|
| 现场汇报 | .pptx | 主交付物 |
| 报审/存档 | PDF | PowerPoint COM 导出(命令见下) |
| 领导快速过目 | 讲义版 PDF(一页4张) | COM 导出时设 HandoutLayout |
| 内部传阅 | 图片版 | 每页 PNG(验收渲染的同款产物复用) |

导出用自带脚本(跨平台双版本):
```bash
# Windows(要求装有 PowerPoint)
powershell -File scripts/export_deck.ps1 deck.pptx 输出目录   # 产出 PDF + 逐页PNG
# macOS / Linux(LibreOffice + Poppler)
bash scripts/export_deck.sh deck.pptx 输出目录
```
讲义版(一页4张,需 PowerPoint COM):
```powershell
$pres.ExportAsFixedFormat("D:\path\handout.pdf", 2, 1, 1, 1, 1, 1, 1, 4)
```
> 两个平台都没有时降级:交付 .pptx 原文件,由用户本地导出。
